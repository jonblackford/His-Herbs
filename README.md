# Montrose Greenhouse — His & Herbs Website

This folder contains a complete static website for **Montrose Greenhouse — His & Herbs**.

It is built as a simple HTML/CSS/JavaScript site, so it can be hosted for free on GitHub Pages without installing Node, React, npm, or any build tools.

## What is included

- `index.html` — the full one-page website
- `assets/` — all website images and favicon
- `.nojekyll` — tells GitHub Pages to publish the site exactly as-is
- `.gitignore` — keeps system files out of the repo
- `robots.txt` — basic search engine crawler file
- `404.html` — fallback page for GitHub Pages
- `BUSINESS_INFO.md` — quick reference for the business details used on the site
- `PUBLISH_TO_GITHUB.md` — step-by-step GitHub Pages publishing guide
- `EDITING_GUIDE.md` — where to change text, photos, links, hours, and contact info

## Quick publish checklist

1. Create a new GitHub repository.
2. Upload everything in this folder to the root of the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/root`
5. Save and wait for GitHub Pages to publish.
6. Open the provided GitHub Pages URL.
